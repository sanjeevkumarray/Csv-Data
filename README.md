# 📊 CSV File Upload to MongoDB using React.js, Node.js, and MongoDB

This web application allows you to **upload data** via CSV file or manual form, **store it in MongoDB**, **display it** in a dynamic table, and **export** the data back to CSV format.  
It also includes **user authentication** to secure the admin panel.

✅ Test CSV files are provided in the repository for quick testing.

---

## 🚀 Features

- ✅ CSV File Upload to MongoDB
- ✅ Manual Data Entry form
- ✅ Data Table Display (View all entries)
- ✅ Export data as CSV
- ✅ Authentication (Secure admin panel)
- ✅ React.js Frontend
- ✅ Node.js + Express.js Backend
- ✅ MongoDB Database
- ✅ Sample Test CSV files included

### 2. Setup Backend (Node.js)

```bash
cd server
npm install
npm start
```

> 🟢 Server will run on `http://localhost:5000`

### 3. Setup Frontend (React.js)

```bash
cd client
npm install
npm start
```

> 🟢 Frontend will run on `http://localhost:5173`

---

## 🧩 How to Use

1. **Login to Admin Panel** (Credentials stored in DB or env file)
2. **Upload CSV** file via upload form
3. Or, **manually enter data** via the input form
4. View data in the **dynamic table**
5. Click **Export** to download all records in CSV format
